# AI-Notes 智能笔记系统概要设计文档

## 1. 引言

### 1.1 文档目的
本文档描述 AI-Notes 智能笔记系统的概要设计，包括系统架构、技术选型、模块划分和数据流设计。本文档面向系统架构师、开发人员和技术管理人员。

### 1.2 项目背景
AI-Notes 是一个基于 AIGC 技术的智能笔记管理系统，旨在帮助用户高效记录和管理知识，并通过 AI 大语言模型提供智能问答功能。

### 2.2 架构特点

#### 2.2.1 服务端渲染 (SSR)
- 使用 Next.js 15 App Router 实现服务端渲染
- 提升首屏加载速度和 SEO 性能
- 支持 React Server Components

#### 2.2.2 API 设计模式
- 使用 Next.js Server Actions 代替传统 REST API
- 类型安全的服务器函数调用
- 减少客户端-服务器通信的样板代码

#### 2.2.3 实时数据同步
- 使用 React 状态管理实现 UI 更新
- 自动保存机制减少数据丢失风险

#### 2.2.4 安全架构
- 所有敏感操作在服务器端执行
- 中间件层进行认证和授权检查
- 环境变量管理敏感配置

### 4.2 核心模块说明

#### 4.2.1 页面模块 (app/)
**职责**: 
- 定义应用路由结构
- 实现页面级组件
- 处理服务端渲染逻辑

**主要文件**:
- `page.tsx`: 主页面，展示笔记编辑器
- `login/page.tsx`: 用户登录页面
- `sign-up/page.tsx`: 用户注册页面
- `layout.tsx`: 全局布局，包含侧边栏和头部

#### 4.2.2 组件模块 (components/)
**职责**:
- 封装可复用的 UI 组件
- 实现用户交互逻辑
- 管理组件内部状态

**主要组件**:
- `AskAIButton`: AI 问答对话框组件
- `NoteTextInput`: 笔记文本编辑器
- `AppSidebar`: 应用侧边栏，显示笔记列表
- `NewNodeButton`: 创建新笔记按钮
- `DeleteNoteButton`: 删除笔记按钮
- `ui/`: 基础 UI 组件库（按钮、对话框、输入框等）

#### 4.2.3 服务器操作模块 (actions/)
**职责**:
- 实现业务逻辑
- 处理数据库操作
- 调用第三方服务

**主要文件**:
- `note.ts`: 
  - `createNoteAction`: 创建笔记
  - `updateTextAction`: 更新笔记内容
  - `deleteNoteAction`: 删除笔记
  - `AskAIAboutNoteAction`: AI 问答处理
- `users.ts`: 用户相关操作

#### 4.2.4 认证模块 (auth/)
**职责**:
- 用户身份验证
- 会话管理
- 权限控制

**主要文件**:
- `server.ts`: 服务端认证逻辑，获取当前用户
- `client.ts`: 客户端认证逻辑，Supabase 客户端配置

#### 4.2.5 数据库模块 (db/)
**职责**:
- 定义数据模型
- 管理数据库连接
- 处理数据库迁移

**主要文件**:
- `schema.prisma`: 数据库 schema 定义
- `prisma.ts`: Prisma 客户端单例
- `migrations/`: 数据库迁移历史

#### 4.2.6 AI 服务模块 (openai/)
**职责**:
- 配置 AI 客户端
- 封装 AI API 调用

**主要文件**:
- `index.ts`: DeepSeek API 客户端配置

### 5.4 数据流特点

#### 5.4.1 单向数据流
- 采用 React 单向数据流模式
- 数据从父组件流向子组件
- 子组件通过回调函数通知父组件

#### 5.4.2 服务端优先
- 敏感操作在服务端执行
- 客户端只处理 UI 交互
- 减少客户端业务逻辑

#### 5.4.3 乐观更新
- 用户操作立即更新 UI
- 后台异步保存数据
- 失败时回滚 UI 状态

## 7. 安全设计

### 7.1 认证和授权
- 所有需要用户数据的操作都需要验证用户身份
- 使用 Supabase 的安全会话机制
- 中间件层拦截未认证请求

### 7.2 数据访问控制
- 数据库查询包含 `authorId` 过滤
- 用户只能访问自己的笔记
- 防止横向越权攻击

### 7.3 输入验证
- 服务端验证所有用户输入
- 防止 SQL 注入（Prisma ORM 提供保护）
- 防止 XSS 攻击（React 自动转义）

### 7.4 敏感信息保护
- API 密钥存储在环境变量
- 不在客户端代码中暴露秘密
- HTTPS 加密传输

## 8. 性能优化

### 8.4 加载优化
