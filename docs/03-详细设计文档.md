## 2. 数据库详细设计

### 2.1 数据模型设计

#### 2.1.1 E-R 图

```
┌─────────────────┐           ┌─────────────────┐
│      User       │           │      Note       │
├─────────────────┤           ├─────────────────┤
│ id (PK)         │1        * │ id (PK)         │
│ email (UNIQUE)  │───────────│ authorId (FK)   │
│ name            │  has many │ text            │
│ createdAt       │           │ createdAt       │
│ updatedAt       │           │ updatedAt       │
└─────────────────┘           └─────────────────┘
```

#### 2.1.2 User 表

**表名**: `User`

**用途**: 存储用户账户信息

| 字段名 | 类型 | 约束 | 描述 |
|--------|------|------|------|
| id | String (UUID) | PRIMARY KEY | 用户唯一标识符 |
| email | String | UNIQUE, NOT NULL | 用户邮箱地址，用于登录 |
| name | String | NULLABLE | 用户昵称 |
| createdAt | DateTime | NOT NULL, DEFAULT NOW | 账户创建时间 |
| updatedAt | DateTime | NOT NULL, DEFAULT NOW | 账户最后更新时间 |

**索引**:
- PRIMARY KEY on `id`
- UNIQUE INDEX on `email`

**关系**:
- 一对多关系：一个用户可以有多个笔记

**Prisma Schema**:
```prisma
model User {
  id        String   @id @default(uuid())
  email     String   @unique
  name      String?
  notes     Note[]
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt @default(now())
}
```

#### 2.1.3 Note 表

**表名**: `Note`

**用途**: 存储用户笔记内容

| 字段名 | 类型 | 约束 | 描述 |
|--------|------|------|------|
| id | String (UUID) | PRIMARY KEY | 笔记唯一标识符 |
| text | String | NOT NULL | 笔记内容文本 |
| authorId | String (UUID) | FOREIGN KEY, NOT NULL | 笔记作者用户 ID |
| createdAt | DateTime | NOT NULL, DEFAULT NOW | 笔记创建时间 |
| updatedAt | DateTime | NOT NULL, DEFAULT NOW | 笔记最后更新时间 |

**索引**:
- PRIMARY KEY on `id`
- INDEX on `authorId` (用于快速查询用户的所有笔记)
- INDEX on `createdAt` (用于按时间排序)

**关系**:
- 多对一关系：多个笔记属于一个用户
- 外键约束：`authorId` 引用 `User.id`

**Prisma Schema**:
```prisma
model Note {
  id        String   @id @default(uuid())
  text      String
  author    User     @relation(fields: [authorId], references: [id])
  authorId  String
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt @default(now())
}
```

### 3.1 Server Actions

#### 3.1.1 createNoteAction

**文件**: `src/actions/note.ts`

**功能**: 创建新的空白笔记

**实现**:
```typescript
export const createNoteAction = async (noteId: string) => {
  try {
    // 1. 获取当前登录用户
    const user = await getUser();
    if (!user) {
      throw new Error("You must be logged in to create a note.");
    }

    // 2. 创建笔记记录
    await prisma.note.create({
      data: {
        id: noteId,        // 客户端生成的 UUID
        authorId: user.id, // 关联到当前用户
        text: "",          // 初始为空内容
      },
    });

    // 3. 返回成功
    return { errorMessage: null };
  } catch (error) {
    // 4. 错误处理
    return handleError(error);
  }
};
```

**参数**:
- `noteId`: string - 客户端生成的 UUID

**返回值**:
- `{ errorMessage: string | null }` - 错误信息或 null

**错误处理**:
- 用户未登录：返回错误信息
- 数据库错误：捕获并返回友好错误信息
- ID 冲突：返回错误信息

**安全考虑**:
- 验证用户身份
- 笔记自动关联到当前用户
- 防止创建他人名下的笔记

```typescript
    // 3. 返回成功
    return { errorMessage: null };
  } catch (error) {
    // 4. 错误处理
    return handleError(error);
  }
};
```

**参数**:
- `noteId`: string - 笔记 ID
- `text`: string - 新的笔记内容

**返回值**:
- `{ errorMessage: string | null }` - 错误信息或 null

**性能优化**:
- 客户端使用防抖（debounce）减少调用频率
- 只更新 text 字段，updatedAt 自动更新

**安全考虑**:
- 验证用户身份
- 需要添加权限检查确保用户只能更新自己的笔记

#### 3.1.4 AskAIAboutNoteAction

**文件**: `src/actions/note.ts`

**功能**: 基于用户笔记内容回答问题

**实现**:
```typescript
export const AskAIAboutNoteAction = async (
  newQuestions: string[],
  responses: string[]
) => {
  // 1. 获取当前登录用户
  const user = await getUser();
  if (!user) {
    throw new Error("You must be logged in to Ask AI.");
  }

  // 2. 获取用户所有笔记
  const notes = await prisma.note.findMany({
    where: { authorId: user.id },
    orderBy: { createdAt: "desc" },
    select: { text: true, createdAt: true, updatedAt: true },
  });

  // 3. 如果没有笔记，返回提示
  if (notes.length === 0) {
    return "你没有笔记";
  }

  // 4. 格式化笔记内容
  const formattedNotes = notes
    .map((note) => {
      return `
      text: ${note.text}
      CreateAt: ${note.createdAt}
      Last update: ${note.updatedAt}
      `.trim();
    })
    .join("\n");

  // 5. 构建 AI 对话消息
  const messages: ChatCompletionMessageParam[] = [
    {
      role: 'system',
      content: `
        You are a helpful assistant that answers questions about a user's notes. 
        Assume all questions are related to the user's notes. 
        Make sure that your answers are not too verbose and you speak succinctly. 
        Your responses MUST be formatted in clean, valid HTML with proper structure. 
        Use tags like <p>, <strong>, <em>, <ul>, <ol>, <li>, <h1> to <h6>, and <br> when appropriate. 
        Do NOT wrap the entire response in a single <p> tag unless it's a single paragraph. 
        Avoid inline styles, JavaScript, or custom attributes.
        
        Rendered like this in JSX:
        <p dangerouslySetInnerHTML={{ __html: YOUR_RESPONSE }} />
  
        Here are the user's notes:
        ${formattedNotes}
      `,
    },
  ];

  // 6. 添加历史对话
  for (let i = 0; i < newQuestions.length; i++) {
    messages.push({
      role: "user",
      content: newQuestions[i],
    });
    if (responses.length > i) {
      messages.push({
        role: "assistant",
        content: responses[i],
      });
    }
  }

  // 7. 调用 AI API
  const completion = await openai.chat.completions.create({
    model: "deepseek-chat",
    messages,
  });

  // 8. 返回 AI 回答
  return completion.choices[0].message.content || "出问题了";
};
```

**参数**:
- `newQuestions`: string[] - 用户提出的所有问题（包括新问题）
- `responses`: string[] - 之前的 AI 回答列表

**返回值**:
- string - AI 生成的 HTML 格式回答

**实现要点**:
1. **上下文管理**: 维护完整的对话历史
2. **笔记格式化**: 将所有笔记格式化为易于 AI 理解的文本
3. **系统提示**: 明确告诉 AI 其角色和回答格式要求
4. **HTML 输出**: 要求 AI 返回格式化的 HTML 便于展示

**性能考虑**:
- 笔记数量多时，上下文可能超过 AI 模型限制
- 可能需要实现笔记摘要或选择性包含

**安全考虑**:
- 验证用户身份
- 只查询当前用户的笔记
- AI 回答内容需要前端安全处理（已使用 dangerouslySetInnerHTML）

#### 3.2.1 getUser

**文件**: `src/auth/server.ts`

**功能**: 获取当前登录用户信息

**实现**:
```typescript
import { createServerClient } from '@supabase/ssr';
import { cookies } from 'next/headers';

export async function getUser() {
  const cookieStore = await cookies();
  
  // 创建 Supabase 服务端客户端
  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() {
          return cookieStore.getAll();
        },
        setAll(cookiesToSet) {
          cookiesToSet.forEach(({ name, value, options }) => {
            cookieStore.set(name, value, options);
          });
        },
      },
    }
  );

  // 获取当前用户
  const { data: { user } } = await supabase.auth.getUser();
  
  return user;
}
```

**返回值**:
- `User | null` - 当前登录用户对象或 null

**使用场景**:
- 所有需要用户身份的 Server Action
- 页面服务端渲染时获取用户信息
- 中间件中的认证检查

### 4.1 笔记编辑功能

#### 4.1.1 NoteTextInput 组件

**文件**: `src/components/NoteTextInput.tsx`

**功能**: 提供笔记文本编辑界面，支持自动保存

**核心实现**:
```typescript
'use client';

import { useState, useEffect, useTransition } from 'react';
import { Textarea } from './ui/textarea';
import { updateTextAction } from '@/actions/note';
import { useDebounce } from '@/hooks/useDebounce';

export default function NoteTextInput({ 
  noteId, 
  startingNoteText 
}: { 
  noteId: string; 
  startingNoteText: string; 
}) {
  // 本地状态
  const [text, setText] = useState(startingNoteText);
  const [isPending, startTransition] = useTransition();
  
  // 防抖处理
  const debouncedText = useDebounce(text, 1000);

  // 自动保存
  useEffect(() => {
    if (debouncedText !== startingNoteText && noteId) {
      startTransition(async () => {
        await updateTextAction(noteId, debouncedText);
      });
    }
  }, [debouncedText, noteId, startingNoteText]);

  return (
    <Textarea
      value={text}
      onChange={(e) => setText(e.target.value)}
      placeholder="开始写笔记..."
      className="min-h-[600px]"
    />
  );
}
```

**设计要点**:
1. **本地状态**: 使用 React state 管理编辑器文本
2. **防抖保存**: 使用 useDebounce hook 延迟 1 秒后保存
3. **乐观更新**: 用户输入立即更新 UI，后台异步保存
4. **条件保存**: 只在内容变化时保存

#### 4.1.2 防抖 Hook

**文件**: `src/hooks/useDebounce.ts`

**实现**:
```typescript
import { useState, useEffect } from 'react';

export function useDebounce<T>(value: T, delay: number): T {
  const [debouncedValue, setDebouncedValue] = useState<T>(value);

  useEffect(() => {
    // 设置定时器
    const handler = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);

    // 清理函数：取消上一次的定时器
    return () => {
      clearTimeout(handler);
    };
  }, [value, delay]);

  return debouncedValue;
}
```

```typescript
'use client';

import { useState } from 'react';
import { useRouter } from 'next/navigation';
import { createClient } from '@/auth/client';

export default function AuthForm({ 
  mode 
}: { 
  mode: 'login' | 'signup' 
}) {
  const [email, setEmail] = useState('');
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const router = useRouter();
  const supabase = createClient();

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setLoading(true);
    setError(null);

    try {
      if (mode === 'login') {
        const { error } = await supabase.auth.signInWithOtp({
          email,
          options: {
            emailRedirectTo: `${window.location.origin}/`,
          },
        });
        if (error) throw error;
        // 显示成功消息
      } else {
        const { error } = await supabase.auth.signUp({
          email,
          options: {
            emailRedirectTo: `${window.location.origin}/`,
          },
        });
        if (error) throw error;
        // 显示成功消息
      }
    } catch (error: any) {
      setError(error.message);
    } finally {
      setLoading(false);
    }
  };

  return (
    <form onSubmit={handleSubmit}>
      {/* 表单UI */}
    </form>
  );
}
```
